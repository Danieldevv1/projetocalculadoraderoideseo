# 📊 Calculadora de ROI de SEO

Uma aplicação Fullstack para simular o retorno sobre investimento (ROI) de campanhas de SEO, projetando receita e lucro ao longo de 12 meses.

![Preview da Calculadora](./preview.png)

## 🚀 Tecnologias Utilizadas
- **Front-end:** React, TypeScript, Vite, Tailwind CSS, Recharts.
- **Back-end:** Node.js, Express, TypeScript, Zod (validação).
- **Funcionalidades:** Exportação de PDF, salvamento de cenários no navegador (localStorage).

## ⚙️ Como rodar o projeto localmente
1. Clone o repositório.
2. Instale as dependências: `npm install`
3. Rode o projeto: `npm run dev`
4. Acesse `http://localhost:3000`
